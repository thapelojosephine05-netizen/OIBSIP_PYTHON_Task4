# Weather App

## Objective
The objective of this project is to create a Python program that allows users to check the current weather in a city or using a South African ZIP code.

1. Asked the user to enter a city name or ZIP code.
2. Checked whether the user entered a valid input.
3. Used the OpenWeatherMap API to request current weather information.
4. Converted the weather data from JSON into information that the program could use.
5. Displayed the location, temperature in Celsius and Fahrenheit, humidity, weather condition, and wind speed.
6. Added error handling for invalid API keys, locations that cannot be found, network problems, and timeouts.

tools i used
- Python
- Visual Studio Code
- Requests library
- OpenWeatherMap API

the outcome
I developed a Weather App that retrieves current weather information from an online API and displays it in the terminal. Users can check the temperature, humidity, weather condition, and wind speed.

what i learned
Through this project, I learned how to use an API to retrieve information from the internet, send HTTP requests, work with JSON data, convert temperatures, and handle errors in Python.

how to run the project
1. Install Python on your computer.
2. Install the Requests library by running `pip install requests` in the terminal.
3. Obtain an API key from OpenWeatherMap.
4. Add your API key to the program without uploading it publicly.
5. Run the Python file and enter a city name or South African ZIP code when prompted.
